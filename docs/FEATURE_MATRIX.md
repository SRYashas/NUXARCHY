# NUXARCHY: Comprehensive Feature Matrix

This feature matrix catalogs all analyzed features from HP OMEN Gaming Hub and OMEN Light Studio, detailing their Linux technical architecture, driver requirements, privilege boundaries, and implementation status in NUXARCHY.

| Feature Name | Reference App | Observed Behavior in Reference | Relevant Windows Components | Linux Implementation Strategy | Required Kernel Interfaces / Services | Hardware Compatibility | Root / Privileges Needed? | Implementation Difficulty | Verification Method | Status |

| **GPU Telemetry (Integrated Graphics)** | Hardware Control Center | Shows iGPU load %, VRAM allocation, and temperature. | `OMENFUNC.dll` (ADL wrapper) | Read DRM sysfs `/sys/class/drm/card*/device/` (`gpu_busy_percent`, `hwmon*/temp1_input`). | `amdgpu` kernel module, DRM sysfs | AMD APUs / Intel Iris | No (Read-only sysfs) | Low | Compare with `radeontop` | Complete & Tested |
| **GPU Telemetry (Dedicated NVIDIA GPU)** | Hardware Control Center | Shows dGPU utilization %, VRAM used/total, clocks, temperature, power draw (W). | `NvidiaApi.dll`, `nvapi64.dll` | Native NVML C API (`pynvml` or `ctypes` bindings to `libnvidia-ml.so.1`) with fallback to `nvidia-smi`. | Proprietary NVIDIA driver / NVML | NVIDIA RTX / GTX GPUs | No (NVML query API) | Medium | Compare with `nvidia-smi` query | Complete & Tested |

| **Network Throughput Monitor** | OMEN Command Center | Real-time upload and download rate in KB/s and MB/s. | `SystemVitals.dll` | Read delta of RX/TX bytes from `/proc/net/dev`. | `/proc/net/dev` | All network adapters | No | Low | Compare with `nload` / `iftop` | Complete & Tested |

| **Max Fan Mode (Cooling Boost)** | OMEN Command Center | Forces fans to 100% maximum RPM to rapidly cool CPU and GPU. | `PerformanceControl.dll`, `WMISDK.dll` | Call HP WMI thermal method or write to EC / `hp-wmi` fan control node if available. | `hp-wmi` kernel module or Polkit helper | HP OMEN laptops | Yes (Polkit privileged helper) | High | Auditory confirmation & RPM telemetry via hwmon | Implemented (Polkit helper) |
| **Custom Fan Curve / Manual Fan Tuning** | OMEN Command Center | Allows user to customize fan speed steps based on CPU/GPU temp thresholds. | `PerformanceControl.dll` (`SwFanControlTable`) | Software fan daemon or mapped thermal triggers. | **GPU Mode Management (Hybrid vs. Discrete MUX)** | OMEN Command Center | Switches display multiplexer between Hybrid (PRIME) and Discrete (NVIDIA direct). | `HP.Omen.GraphicsSwitcherModule.dll` | 1.
